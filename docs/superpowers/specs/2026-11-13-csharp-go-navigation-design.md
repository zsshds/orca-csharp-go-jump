# Orca C# 与 Go 代码导航插件设计

## 目标与范围

为 Orca 本地工作区提供 C#（`.cs`）和 Go（`.go`）文件编辑视图及语言内语义导航。参考 MIT 许可的 JumpLens 的宿主集成和交互方式；复用代码时保留适用的版权与许可证声明。首版不包含 C# 与 Go 之间的业务映射、Git 提交阅读或自动下载运行环境。

## 编辑器与宿主

使用 Orca custom editor、独立 worker 和 CodeMirror。编辑器提供语法配色、行号、代码折叠、括号补全、Tab 缩进、搜索、替换、撤销和重做。通过 Orca 文档会话读取和修改内容；保存和外部修改冲突遵循宿主机制。插件不绕过文档会话写入打开的文件。

## 语言服务与项目

使用 LSP：Go 使用 `gopls`，C# 优先使用 `csharp-ls`。实现前验证 C# 服务许可证、启动方式和所需 LSP 方法支持。按文件所属项目识别服务工作区，并向服务同步文档打开、增量或完整修改及关闭事件，使导航反映未保存内容。设置允许指定服务可执行文件路径；默认从系统 PATH 查找。启动和加载失败时显示具体原因与安装提示，并支持重新连接。语言服务不可用时基本编辑功能仍可用。

## 导航交互

工具栏提供定义、类型定义、实现、引用、返回和前进。F12 与 Ctrl/Cmd+点击跳转定义。单个结果直接打开，多个结果展示可筛选的候选列表与源码预览；没有结果时给出提示。导航历史保存文件与光标位置。正确处理 LSP 位置编码和文件 URI；请求结果与文档版本关联，过期结果不覆盖当前状态。对不能由 Orca 打开的外部或虚拟文件，应展示明确提示，不得误认为导航成功。

## 错误处理

区分可执行文件缺失、启动失败、项目加载失败、请求超时及服务不支持的操作。任何语言服务故障都不阻塞编辑和宿主保存。重新连接应释放旧进程和请求，并重新同步打开的文档。

## 验证

自动化测试覆盖文档同步、位置和 URI 转换、单个及多个导航结果、导航历史、旧结果丢弃、服务故障和重新连接。使用真实 C# 和 Go 示例项目验证跨文件定义、类型、实现、引用、未保存修改以及宿主保存和冲突行为。真实服务或 Orca 环境不可用时，记录具体未验证项目，不将模拟测试等同于真实集成验证。
